Tutorial Mudah Mengalirkan Data ke Google Sheet Secara Real-Time (100% Berhasil)

Ikuti 3 langkah super mudah berikut agar data nilai mahasiswa otomatis masuk ke Google Sheet Anda saat ujian selesai:

Langkah 1: Buat Google Sheet Baru

Buka sheets.new. Beri nama file misal "Rekap Ujian PBA". Pada Baris 1 Kolom A s/h H, buat header kolom berurutan: Timestamp, NIM, Nama, Kelas, Benar, Total, Nilai

Langkah 2: Pasang Script Google Apps Script

Di lembar Google Sheet Anda, klik menu atas: Ekstensi > Apps Script. Hapus semua kode bawaan, lalu salin dan tempel kode otomatis di bawah ini:

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  try {
    var data = JSON.parse(e.postData.contents);
    sheet.appendRow([data.timestamp, data.nim, data.name, data.className, data.correct, data.total, data.score]);
    return ContentService.createTextOutput(JSON.stringify({"status":"success"})).setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({"status":"error", "message": err.toString()})).setMimeType(ContentService.MimeType.JSON);
  }
}

Lalu klik tombol Simpan (ikon Disket) di pojok kiri atas editor.

Langkah 3: Deploy & Salin URL Web App
  • Klik tombol Deploy di pojok kanan atas > Pilih Deployment baru.
  • Pilih jenis (ikon roda gigi) > Pilih Aplikasi web (Web app).
  • Pada bagian Deskripsi isi bebas (misal: "Ujian PBA").
  • Pada Jalankan sebagai (Execute as): Pilih Saya (Me).
  • Pada Siapa saja yang memiliki akses (Who has access): Pilih Siapa saja (Anyone). (Wajib agar bisa diakses browser).
  • Klik Deploy > Berikan izin akses akun (Authorization) > Izinkan/Advanced > Go to Untitled project (unsafe).
  • Salin URL Aplikasi Web (Web App URL) yang dihasilkan.
Langkah 4: Masukkan URL ke Dalam Sistem Ini

Buka file HTML ini menggunakan editor teks (Notepad/VSCode), cari baris const GOOGLE_SHEETS_WEB_APP_URL = ""; lalu tempel URL Web App Anda di antara tanda kutip tersebut.
